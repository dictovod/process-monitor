# 🔍 Process Monitor Pro

Telegram-бот для мониторинга новых процессов на Linux-сервере в реальном времени. Уведомляет о каждом новом процессе, позволяет управлять фильтрами прямо из чата.

## Возможности

- **Мониторинг в реальном времени** — проверка новых процессов каждые 5 секунд
- **Три режима фильтрации** — чёрный список, белый список, умный режим
- **Маски (regex)** — одной маской `runc` накрываешь `runc:[2:INIT]`, `runc:[1:CHILD]` и т.д.
- **Группировка уведомлений** — несколько процессов за период приходят одним сообщением
- **Тихие часы** — нет уведомлений в указанное время
- **Пороги CPU/RAM** — игнорировать процессы ниже порога
- **Статистика** — история запусков каждого процесса
- **Экспорт списков файлами** — получить JSON со всеми фильтрами для анализа
- **Автообновление** — один скрипт заменяет бота и перезапускает сервис, токен сохраняется

## Быстрый старт

### 1. Установка

```bash
wget -O /root/monitor.py "https://raw.githubusercontent.com/dictovod/process-monitor/main/monitor_server.py"
```

### 2. Вставить токен

```bash
sed -i 's/TELEGRAM_TOKEN = ".*"/TELEGRAM_TOKEN = "ВАШ_ТОКЕН"/' /root/monitor.py
```

### 3. Создать systemd-сервис

```bash
cat > /etc/systemd/system/process-monitor.service << 'EOF'
[Unit]
Description=Process Monitor Telegram Bot
After=network.target

[Service]
Type=simple
ExecStart=/usr/bin/python3 /root/monitor.py
Restart=always
RestartSec=5
User=root

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable --now process-monitor
```

### 4. Проверить статус

```bash
systemctl status process-monitor
```

## Обновление

Одна команда — скачивает новую версию, сохраняет токен, перезапускает сервис:

```bash
wget -qO /root/update_monitor.sh "https://raw.githubusercontent.com/dictovod/process-monitor/refs/heads/main/update_monitor.sh" && bash /root/update_monitor.sh
```

Если что-то пошло не так — автоматически откатывается на старую версию (`/root/monitor.py.bak`).

## Команды бота

| Команда | Описание |
|---|---|
| `/start` | Активировать уведомления |
| `/stop` | Отключить уведомления |
| `/status` | CPU, RAM, диск, открытые порты |
| `/settings` | Настройки режимов и фильтров |
| `/list` | Просмотр игнорируемых процессов |
| `/whitelist` | Просмотр белого списка |
| `/imask [маска]` | Добавить/просмотреть маски игнора |
| `/wmask [маска]` | Добавить/просмотреть маски белого списка |
| `/history <имя>` | История запусков процесса |
| `/quiet 22:00-08:00` | Установить тихие часы |
| `/quiet off` | Отключить тихие часы |
| `/setcpu 5` | Порог CPU в % (игнорировать ниже) |
| `/setram 100` | Порог RAM в MB (игнорировать ниже) |

## Кнопки при уведомлении о процессе

Когда приходит уведомление о новом процессе, доступны кнопки:

| Кнопка | Действие |
|---|---|
| 🚫 Игнор точно | Добавить точное имя в чёрный список |
| ⭐ Вайтлист точно | Добавить точное имя в белый список |
| 🔇 Игнор маску `runc*` | Игнорировать все процессы содержащие `runc` |
| ✅ Вайтлист маску `runc*` | Разрешить все процессы содержащие `runc` |
| 📊 Статистика | История запусков этого процесса |

## Режимы фильтрации

**🚫 Чёрный список** (по умолчанию) — уведомлять обо всём, кроме явно игнорируемых.

**⭐ Белый список** — уведомлять только о процессах из белого списка. Всё остальное молча пропускать.

**🧠 Умный** — белый список имеет приоритет (всегда уведомлять), чёрный список подавляет остальные.

## Маски

Маски поддерживают обычное вхождение строки и regex:

```
runc        → поймает runc:[2:INIT], runc:[1:CHILD], runc-helper
kworker     → поймает kworker/0:1, kworker/u4:2
myapp       → поймает myapp, myapp-worker, myapp_v2
kworker/\d+ → только kworker с номером (regex)
```

Добавить маску вручную:
```bash
# через бота
/imask runc
/wmask myapp

# или через команду сервера не нужно — всё через бота
```

## Экспорт списков

В главном меню → **Экспорт списков** → получить JSON-файлы с текущими фильтрами. Удобно для резервной копии или анализа накопившихся записей.

## Файловая структура

```
/root/
├── monitor.py                          # основной файл бота
├── monitor.py.bak                      # резервная копия (создаётся при обновлении)
├── update_monitor.sh                   # скрипт обновления
└── Desktop/process-monitor/
    ├── ignored_processes.json          # чёрный список
    ├── whitelist.json                  # белый список
    ├── ignored_masks.json              # маски игнора
    ├── whitelist_masks.json            # маски белого списка
    ├── active_users.json               # активные пользователи
    ├── user_settings.json              # настройки пользователей
    ├── stats.json                      # статистика процессов
    └── monitor.log                     # лог работы бота
```

## Требования

- Debian/Ubuntu Linux
- Python 3.8+
- systemd
- Зависимости устанавливаются автоматически: `psutil`, `requests`
